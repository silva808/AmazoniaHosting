1.1 Introducción 

El proyecto surge a partir de una problemática identificada en la región Amazónica relacionada con la falta de información sobre las opciones de hospedaje tanto temporal o fijo disponibles en el territorio. Actualmente encontrar información sobre viviendas, hoteles, hostales, residencias y otros tipos de alojamientos puede resultar difícil para turistas y residentes; debido a la poca disponibilidad de plataformas que agrupen estos servicios de manera organizada. Por esta razón, se propone desarrollar AmazoniaHosting, una plataforma que permita conectar directamente a los usuarios con los propietarios o encargados de los establecimientos de hospedaje, facilitando la consulta y la disponibilidad de estos alojamientos.
Nuestro primer modelo UML pasó de tener roles asignados en una clase de enumeración a aplicarlos por medio de la herencia (Huésped y Propietario como subclases de Usuario), y se modificó la información de las clases para evitar datos repetidos entre ellas: la clase Disponibilidad se integró en Propiedad (atributos precio y estadoDisponibilidad). Se mejoró el flujo de las relaciones entre propiedad y publicación con los usuarios, se estableció la clase Reservacion para el control de la disponibilidad por fechas, se incorporó la clase Resena para la calificación de los alojamientos y, por último, se añadió la clase GestorReporte para recopilar los datos y la información de los distintos apartados del sistema.
El proyecto AmazoniaHosting se organiza mediante tres paquetes principales: .mundo, .interfaz, .test. En .mundo se encuentra toda la lógica y las clases propuesta por el diagrama UML. En .interfaz se encuentra encargado de manejar las interacciones con el usuario mediante menús por consola. Finalmente .test hace las pruebas para verificar que las funciones del sistema trabajen correctamente.
